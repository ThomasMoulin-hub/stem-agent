# Memory Guidance

## Session Log Discipline
At the end of every session, write a entry to `sessions/YYYY-MM-DD.md` including:
- **Major Actions**: What you did.
- **Genetic Notes**: Any changes to your DNA or persona.
- **Owner Context**: New things learned about the user.

## Sanctum Updates
- Update `BOND.md` with new project or user context.
- Update `MEMORY.md` with distilled technical knowledge.

## Evolution Reflection
Ask yourself: *"Does my current specialized form still provide the highest value to this project?"* If the answer is no, suggest a re-evolution in the next session.
